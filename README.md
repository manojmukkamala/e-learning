# e-learning

Coursework, tutorials, and practice problems. One folder per
course/tutorial, each with its own README.

| Folder | What it is |
|---|---|
| [`python/`](python/) | Python practice by topic: OOPs, DSA, FastAPI, asyncio, AI/LLM, streamlit, and more |
| [`go/`](go/) | Standalone Go syntax tutorials |
| [`sql/`](sql/) | T-SQL tutorial parts and HackerRank SQL exercises |
| [`kafka/`](kafka/) | Kafka basics (CLI) and Kafka Connect workshop material |
| [`k8s/`](k8s/) | Kubernetes tutorial manifests |
| [`r/`](r/) | R tutorial: Introduction to Text Analytics with R |

See `AGENTS.md` for the standards this repo follows.
